# Data Professional Survey Dashboard

## Overview
This Power BI dashboard analyzes survey data collected from data professionals across different countries, job roles, programming languages, and salary levels. The dashboard provides insights into salary trends, work satisfaction, favorite programming languages, and demographic information.

---

## Tools Used
- Power BI
- Excel
- Data Visualization

---

## Dashboard Features
- Average salary analysis by job title
- Country-wise distribution of survey participants
- Favorite programming language analysis
- Yearly salary distribution by gender
- Happiness with salary rating
- Happiness with work-life balance rating
- Count of survey participants
- Average age analysis

## Key Insights
- Data Analysts have the highest average salary among surveyed roles.
- Most survey participants are from the United States and India.
- Python is the most preferred programming language among data professionals.
- Male participants represent the majority of survey responses.
- Overall work happiness is higher than salary happiness.
